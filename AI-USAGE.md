# AI Usage

AI assistance was used during development to:

- inspect and organize the supplied challenge materials;
- explain the supplied baseline and validator;
- propose an ML feature/validation structure;
- draft and review repository documentation and code structure;
- identify potential leakage and reproducibility issues.

All final methodological choices should be reviewed and understood by the candidate before submission. The challenge data itself is processed locally by the repository scripts; no external AI service is required at runtime.
